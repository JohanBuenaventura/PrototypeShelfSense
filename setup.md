Step 1: Create the Vite React Project
Open your VSCode Terminal (Terminal > New Terminal) and run:

Bash

npm create vite@latest shelfsense -- --template react-ts
Navigate into your new project folder:

Bash

cd shelfsense

Install the base React dependencies:

Bash

npm install

Step 2: Install Tailwind CSS v4 & Lucide Icons
Run the following npm install commands in your terminal:

Install Tailwind CSS v4 Vite plugin:

Bash
npm install -D tailwindcss @tailwindcss/vite

Install Lucide React (for Icons):

Bash
npm install lucide-react
